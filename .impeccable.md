## Design Context

### Users

**Visiteurs publics** : Citoyens ivoiriens, majoritairement jeunes (18-35 ans), naviguant principalement sur mobile. Ils decouvrent le parti, lisent les actualites et decident d'adherer. Contexte : connexion mobile parfois instable (3G/4G), habitudes UX influencees par WhatsApp, Facebook et les apps de mobile money.

**Partisans (membres inscrits)** : Adherents du parti qui consultent leur profil, suivent les actions du parti et souhaitent se sentir integres a un mouvement. Ils accedent a la plateforme depuis le web ou la future app Flutter.

**Administrateurs** : Responsables du parti qui gerent les adhesions, publient du contenu, consultent les statistiques et structurent l'organisation. Ils travaillent principalement sur desktop, parfois tablette.

**Job to be done** :
- Visiteur : "Comprendre rapidement ce qu'est le FPP et rejoindre le mouvement en 2 minutes"
- Partisan : "Voir que mon adhesion est prise en compte et suivre la vie du parti"
- Admin : "Piloter le parti avec des donnees fiables et publier du contenu facilement"

### Brand Personality

**3 mots** : Audacieux, Jeune, Panafricain

**Ton** : Institutionnel mais accessible. Pas de jargon politique excessif. Phrases courtes, directes, orientees action. Le parti parle a la jeunesse sans etre condescendant -- il inspire et mobilise.

**Emotions cibles** :
- **Espoir** : Un avenir meilleur est possible, rejoignez le mouvement
- **Urgence** : Le moment d'agir c'est maintenant
- **Energie** : Un parti dynamique, en mouvement, pas un appareil politique fige
- **Confiance** : Une organisation serieuse, structuree, transparente

### Aesthetic Direction

**Style** : Swiss Modernism 2.0 + Flat Design — epure, geometrique, structure, avec une touche de chaleur humaine (photos de terrain authentiques, pas de stock photos generiques).

**Theme** : Light mode uniquement. Pas de dark mode.

**Palette** : Noir institutionnel (#111111) + Blanc pur (#FFFFFF) + Vert accent panafricain (#16A34A). Tous les gris teinetes vers hue 145 (vert). Regle 60-30-10.

**Typographie** : Outfit (titres -- audacieux, moderne) + Work Sans (corps -- lisible, humain). Echelle major third (1.25).

**References** :
- [ONE.org Africa](https://www.one.org/africa/fr/) -- engagement, clarte, sections aerees, CTA forts, ton mobilisateur
- Prototype v0 existant (v0-political-party-website-umber-ten.vercel.app) comme base de depart

**Anti-references** (ce que le FPP ne doit PAS etre) :
- Sites politiques anciens/charges (fonds sombres, typographie serree, trop de texte)
- Esthetique "AI-generated" (degradees violet-bleu, glassmorphism gratuit)
- Sites corporate froids sans ame (stock photos, langage generique)
- Interfaces Flutter/Material par defaut sans direction visuelle

### Design Principles

1. **Clarte avant tout** : Chaque page doit pouvoir etre comprise en 5 secondes. Hierarchie visuelle forte, messages courts, CTAs explicites. Si c'est confus, c'est rate.

2. **Mobile-first, Afrique-first** : Concevoir pour le mobile 3G/4G d'abord. Images optimisees, lazy loading, squelettes de chargement, pas de dependance a une connexion rapide.

3. **Sobriete institutionnelle + energie jeune** : Le noir et blanc apportent la credibilite, le vert accent apporte l'energie. Ne jamais sacrifier l'un pour l'autre.

4. **Engagement a chaque scroll** : Chaque section doit donner envie d'aller plus loin ou d'agir. Pas de sections decoratives sans objectif. Le CTA d'adhesion doit etre omnipresent sans etre intrusif.

5. **Accessibilite non-negociable** : WCAG AA minimum. Contraste 4.5:1, navigation clavier, focus visible, `prefers-reduced-motion` respecte, labels explicites sur tous les formulaires.

### Accessibility Requirements

- **Niveau** : WCAG 2.1 AA
- **Contraste texte** : 4.5:1 minimum (corps), 3:1 (grands textes/titres)
- **Navigation clavier** : Focus visible sur tous les elements interactifs
- **Motion** : Respecter `prefers-reduced-motion: reduce`
- **Formulaires** : Labels visibles, messages d'erreur clairs et associes, validation temps reel
- **Images** : Alt text descriptif, pas d'information transmise uniquement par la couleur
- **Responsive** : 375px (mobile), 768px (tablette), 1024px (desktop), 1440px (grand ecran)
